# MathDoc frontend

Svelte and Monaco. `npm run build -w mdc-web` writes the ignored `web/dist`, which the
TypeScript backend serves at `/` and `/p/<database>/<branch>/`. Lean blocks are ordinary
source editors; proofs are checked by LeanGround through the collaboration views.
