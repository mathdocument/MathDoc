## One source of truth

MathDoc stores each definition, result, or note in a readable `.mdoc` file. A stable
identity and explicit dependency list connect those files into a graph; typed source
blocks keep formal and computational work beside the mathematical idea they support.

## The core loop

```bash title="A complete MathDoc workflow"
mdc init
mdc new -t "Background Lemma" -f notes/background
mdc new -t "Main Theorem" -f notes/theorem
mdc dep add notes/theorem --target notes/background
mdc sync
mdc work notes/theorem
mdc back
mdc graph check
```

The `.mdoc` files remain authoritative. Generated mirrors under `.mdc/` provide the
stable paths and project layouts expected by language-native editors and compilers.
