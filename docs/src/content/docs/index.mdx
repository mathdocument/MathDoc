---
title: MathDoc
description: Versioned mathematical graphs with native Lean editing.
---

MathDoc stores connected mathematical knowledge in **TerminusDB** and serves it
through a local browser and CLI. One entry point lists all projects and routes
to each branch's independent service. Nodes contain text, Lean, Rocq and LaTeX blocks.
Lean uses native Lean Server, Monaco and Infoview for incremental proof editing.
Only Lean compilation is integrated; other block types remain editable sources.

[Install and run MathDoc](getting-started/installation/) · [Quick start](getting-started/quick-start/)

All writes are versioned database transactions. There is no filesystem refresh
before ordinary commands. Explicit import/export replaces source synchronization.
The browser and agents share the same API and revision checks.
